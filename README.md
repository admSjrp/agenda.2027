# Agenda CCB Rio Preto 2027

Versão digital da agenda da Congregação Cristã no Brasil, Administração São José do Rio Preto.

Endereço: https://admsjrp.github.io/agenda.2027/

- `index.html` é gerado pelo script `gerar_site.py` (pasta da Secretaria) a partir da planilha pública "Agenda CCB Rio Preto 2027".
- Ao abrir, a página lê a planilha ao vivo; se não conseguir, usa a cópia embutida no arquivo.
- Este repositório não contém nomes do ministério.
